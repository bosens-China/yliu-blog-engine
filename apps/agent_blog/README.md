# Agent Blog

基于 AI 的博客内容智能增强服务，使用 FastAPI + LangGraph 构建的现代化 AI 处理流水线。

## 🎯 功能特性

- 📝 **智能摘要**：自动生成文章摘要和 SEO 信息
- 📚 **专栏分类**：基于内容相似度智能生成专栏分组
- 🔍 **SEO 优化**：自动生成站点级别的 SEO 元数据
- ⚡ **高性能缓存**：基于文件的智能缓存机制，避免重复处理
- 🔄 **流式处理**：使用 LangGraph 构建的可扩展处理流水线

## 🏗️ 技术架构

```
┌─────────────────┐    HTTP POST    ┌──────────────────┐
│ packages/scripts│ ───────────────> │   FastAPI Server │
└─────────────────┘                 └──────────────────┘
                                             │
                                             ▼
                                    ┌──────────────────┐
                                    │   LangGraph      │
                                    │   WorkFlow       │
                                    └──────────────────┘
                                             │
                        ┌────────────────────┼────────────────────┐
                        ▼                    ▼                    ▼
                ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
                │   文章处理    │    │   专栏生成    │    │  站点 SEO    │
                │   节点       │    │   节点       │    │   节点       │
                └──────────────┘    └──────────────┘    └──────────────┘
```

## 🚀 工作流程

1. **接收请求**：`packages/scripts` 发送文章列表到 `agent_blog` 服务
2. **内容处理**：FastAPI 接收文章数据，传入 LangGraph 工作流
3. **AI 增强**：通过多个处理节点完成智能分析和生成
4. **返回结果**：以 JSON 格式返回处理后的增强数据

## 💡 设计理念

### 轻量化架构

专为 CI 环境设计，最大程度减少资源占用和启动时间。

### 智能缓存

- **内存缓存**：运行时高速访问
- **磁盘持久化**：防抖写入，避免频繁 I/O
- **版本控制**：支持 schema 版本管理，确保数据兼容性

### 工程最佳实践

- 使用 `uv` 进行依赖管理
- 采用 `src` 目录结构
- 遵循 Python 类型注解规范

## 🛠️ 本地开发

### 环境要求

- Python 3.12+
- uv 包管理器

### 启动服务

```bash
# 安装依赖
uv sync

# 启动开发服务器
uv run uvicorn src.main:app --reload --host 0.0.0.0 --port 8000
```

### 环境变量

```bash
# .env 文件
OPENAI_API_KEY=your_openai_api_key_here
```

## 📡 API 接口

### POST `/process`

处理文章列表，返回 AI 增强后的数据。

**请求格式：**

```json
[
  {
    "id": 1,
    "title": "文章标题",
    "content": "文章内容",
    "createdAt": "2024-01-01T00:00:00Z",
    "updatedAt": "2024-01-01T00:00:00Z"
  }
]
```

**响应格式：**

```json
{
  "message": "处理成功",
  "data": {
    "articles": [...],
    "columns": [...],
    "site_seo": {...}
  }
}
```

## 🔧 配置说明

服务会自动从以下位置读取缓存文件：

- 缓存文件：`agent_blog_cache.json`
- Schema 版本：`1.0`
- 防抖延迟：`2.0` 秒

## 📈 性能优化

- **增量处理**：只处理内容发生变化的文章
- **并发处理**：使用 `asyncio.gather` 并发处理多篇文章
- **智能缓存**：基于内容哈希的精确缓存策略
