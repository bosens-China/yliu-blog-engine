# AI 增强配置

用于启用和配置 AI 增强功能的变量。

| 变量名           | 描述                                                                                                              |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| `OPENAI_API_KEY` | 用于 AI 增强功能的 API Key。提供此密钥将激活所有 AI 功能，例如 SEO 优化和专栏生成。该密钥可从阿里云百炼服务获取。 |
