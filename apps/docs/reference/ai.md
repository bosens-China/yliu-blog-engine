# AI 增强配置

用于启用和配置 AI 增强功能的变量。

| 变量名                | 描述                                                                                                                                                           | 默认值                                                 |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `OPENAI_API_KEY`      | **[必需]** 用于 AI 增强功能的 API Key。提供此密钥将激活所有 AI 功能。该密钥可从阿里云百炼服务获取。                                                              | (无)                                                   |
| `OPENAI_MODEL_NAME`   | 指定使用的 LLM 模型名称。                                                                                                                                      | `qwen-plus-2025-07-28`                                 |
| `OPENAI_BASE_URL`     | 指定 LLM API 的基地址。                                                                                                                                        | `https://dashscope.aliyuncs.com/compatible-mode/v1`    |
| `LLM_RPM_LIMIT`       | 设置对 LLM API 的每分钟请求数（RPM）限制。这有助于避免因请求过于频繁而导致的 `429` 错误。 | `50`                                                   |
| `LLM_BURST_LIMIT`     | 设置 LLM API 的并发请求突发数限制。这是防止 `429` 错误的关键，因为它直接控制了瞬间的请求数量。 | `5`                                                    |
