# 高级选项

本页包含不常用但可能在特定场景下有用的高级配置。

## SEO 兜底

当 AI 服务未启用或执行失败时，系统将使用以下变量作为 SEO 元数据的兜底值。

| 变量名                        | 描述                                      |
| ----------------------------- | ----------------------------------------- |
| `NEXT_PUBLIC_SEO_DESCRIPTION` | 站点的全局元描述。                        |
| `NEXT_PUBLIC_SEO_KEYWORDS`    | 站点的全局关键词（用英文逗号 `,` 分隔）。 |
