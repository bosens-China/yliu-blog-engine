# AI 增强

通过集成的 `agent-blog` AI 助手，您可以将您的博客提升到一个新的水平。该功能在 GitHub Action 工作流中自动运行，为您的内容实现自动化 SEO 优化和智能组织。

## 功能概览

与之前分散的 AI 服务不同，新架构采用了一个统一的 AI Agent 服务，它会一次性地、智能地完成以下所有任务：

1.  **文章 SEO 优化**: 为每篇文章生成摘要和 SEO 关键词。
2.  **专栏智能分析**: 自动分析所有文章，将内容相关的文章组织成专栏，并为专栏生成描述。
3.  **全站 SEO 汇总**: 基于所有文章内容，为您的整个博客生成一个全局的、一致的 SEO 策略。

## 配置与密钥申请

启用 AI 增强功能非常简单。您只需要从阿里云百炼平台申请一个 API Key，并将其配置为您 GitHub 仓库的 Secret 即可。

1.  前往 [阿里云百炼大模型平台](https://bailian.console.aliyun.com/) 申请您的 API Key。
2.  在您的 GitHub 仓库中，前往 `Settings` > `Secrets and variables` > `Actions`。
3.  点击 `New repository secret`，创建一个名为 `OPENAI_API_KEY` 的 Secret，并将您获取到的 Key 粘贴进去。

> **兼容性说明**
> 尽管 API Key 来自阿里云，但 `agent-blog` 使用的接口标准与 OpenAI 兼容。因此，您需要将 Secret 命名为 `OPENAI_API_KEY` 以确保工作流能够正确识别。

## 工作原理

`agent-blog` 是一个基于 LangGraph 构建的智能代理。在工作流中，它会接收所有文章，并按照预设的逻辑图（Graph）有序地执行以下操作：

- **节点 1 (文章处理)**: 并发地为每篇文章生成摘要和关键词。
- **节点 2 (专栏分组)**: 基于文章标题进行智能分组。
- **节点 3 (专栏描述)**: 为分组后的专栏生成描述。
- **节点 4 (站点SEO)**: 汇总所有信息，生成全局SEO。

这种架构不仅高效，而且具有很强的可扩展性，未来可以方便地加入更多的 AI 处理节点。
